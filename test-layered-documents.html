🔬 Layered Document Processing Test Interface

📋 Instructions

This test interface allows you to test the layered document processing system with sample documents.

The system processes documents into 3 layers:

  • Layer 1: Short summary (~500 tokens) + Word bank (~200 tokens)
  • Layer 2: Comprehensive facts (~2000 tokens) OR full content if ≤2000 tokens
  • Layer 3: Full document text (only for >2000 token documents)

Note: Make sure the Python backend is running with the new generate-text endpoint.
